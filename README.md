# Azeroth Surfers

An endless 3D runner where you chase high scores all around Azeroth.

Play a quick run while waiting for your group, or keep going to beat your personal record.

## Features

- **Familiar zones each with its own wildlife and scenery** (Elwynn Forest, Durotar, ...)
- **Three-lane auto runner gameplay with direct fluid controlls**
- **4 Different difficulties and custom runs**
- **Daily, weekly, and monthly challenges**
- **Guild and group leaderboards**
- **Personal records and stats**
- **Fullscreen or windowed**
- **Keyboard and gamepad controls** (Rebind the controls in the addon settings)

## Getting started

Type **`/surfers`** or click the **minimap icon** to open the game. Choose **Play** from the main menu to start a run.

Default keyboard controls:

| Action         | Key                          |
| -------------- | ---------------------------- |
| Switch lanes   | A / D or Left / Right arrows |
| Jump           | Space or Up arrow            |
| Duck / drop    | S or Down arrow              |
| Pause / resume | Q                            |
| Restart        | R — hold during a run        |

Open **`/surfers options`** to adjust the display, sound, controls, and other settings.

## Note

The addon can only reuse models and animations from the game, and on Era the characters dont have a roll animation, so it is replaced by the swimming animation.
